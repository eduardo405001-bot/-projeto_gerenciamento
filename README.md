\# Projeto de Gerenciamento de Configuração



Este projeto foi desenvolvido como atividade prática

da disciplina Projeto de Software.



Objetivo:

Aprender a utilizar o Git e o GitHub para controlar

as versões e modificações dos arquivos de um projeto.



Ferramentas utilizadas:

\- Git

\- GitHub

\- Python



Atividade prática realizada:

Criação, modificação e atualização de artefatos.
